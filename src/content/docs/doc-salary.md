급여 혹은 연봉을 입력하였을 때 매월 급여에서 공제되는 **4대 보험** 및 **소득세/지방소득세**는 보건복지부, 고용노동부, 국세청의 최신 공제율을 따릅니다.

| 구분 | 공제율 (근로자 부담분) | 비고 |
| :--- | :--- | :--- |
| **국민연금** | 4.50% | 월 소득 기준 상한액(2025/2026년 기준 6,170,000원) 적용 |
| **건강보험** | 3.54% | 보수월액 기준 요율 |
| **장기요양보험** | 건강보험료의 12.95% | 보건복지부 고시 기준 |
| **고용보험** | 0.90% | 실업급여 부담분 기준 |
| **근로소득세** | 국세청 간이세액표 기준 | 본인 및 부양가족 수에 따라 차등 부과 |
| **지방소득세** | 근로소득세의 10.0% | 지방세법 기준 |
