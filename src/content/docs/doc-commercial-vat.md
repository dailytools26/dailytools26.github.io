상가 매매 시 토지 지분은 부가가치세 면세 대상이지만, 건물분은 10% 과세 대상입니다. 계약 시 총액으로 거래할 경우, 국세청 기준 시가를 안분하여 적정한 건물분 공급가액과 부가세를 합리적으로 나눕니다.

<div class="formula-box">
  <span class="formula-title">건물분 안분 공식</span>
  <code>건물 안분액 = 총 거래 금액 * (건물 기준시가 / (건물 기준시가 + 토지 기준시가))</code>
  <code>건물분 부가가치세 = 건물 안분액 * 10%</code>
</div>
