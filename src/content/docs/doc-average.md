기존 보유 주식에 새로운 주식을 추가로 매수하였을 때 가중평균을 반영하여 평균 매수 단가를 구합니다.

<div class="formula-box">
  <span class="formula-title">가중 평균 단가 산식</span>
  <code>최종 평단 = (기존 평단 * 기존 수량 + 추가 평단 * 추가 수량) / (기존 수량 + 추가 수량)</code>
  <code>총 투자금 = 최종 평단 * (기존 수량 + 추가 수량)</code>
</div>
